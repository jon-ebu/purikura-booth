# PURI★BOOTH

A single-file webcam purikura (プリクラ) photobooth: green-screen keying, beauty glow, 4-shot countdown, then a decorate stage with pens and stamps. Exports a PNG sheet.

Open `index.html` over HTTPS or `localhost` (the camera needs a secure context), e.g. `python3 -m http.server`, or serve it with GitHub Pages.
